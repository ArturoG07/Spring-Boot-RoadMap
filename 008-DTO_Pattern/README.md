# 008 - DTO Pattern

Spring Boot application with a REST Controller with a get endpoint that returns a PropertyDTO with combined data from Property and Guest classes


## Endpoints
- `GET /property/{id}` — Returns a PropertyDTO

## Stack
- Java 26
- Spring Boot 4.x
- Maven

## Testing
- Postman

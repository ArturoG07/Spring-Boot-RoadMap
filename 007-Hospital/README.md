# 007 - Hospital

Spring Boot application with a REST Controller

Tested with Postman.

## Endpoints
- `GET /patients` — Returns a list of patients
- `GET /patients/under18` — Returns a list of patients under 18 years
- `GET /patient` — Returns a specific client with the ID given on the URL (or a default client if none are found)
- `POST /patient` — Prints a new patient with the data given on body

## Stack
- Java 26
- Spring Boot 4.x
- Maven

## Testing
- Postman

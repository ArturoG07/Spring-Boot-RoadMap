# 014-CRUD
This project demonstrates how to implement CRUD operations using Spring Boot, JPA, and Hibernate with a MySQL database.
## Stack
- Java 25
- Spring Boot 4.x
- Maven
- MySQL 8.x
- JPA + Hibernate
- Postman (for testing the endpoints)

## Author
**ArturoG07** · [Spring Boot RoadMap](https://github.com/ArturoG07/Spring-Boot-RoadMap)

## Steps

### 1. JPA + Hibernate configurations (previously done in the project)
### 2. Create the service interface and implementation
### 3. Create the controller class and define the endpoints for CRUD operations
### 4. Test the endpoints using Postman or any other API testing tool

## Endpoints
- `GET /users/{id}` - Retrieve a user by ID
- `POST /users` - Create a new user
- `PUT /users/{id}` - Update a user by ID
- `DELETE /users/{id}` - Delete a user by ID

# 009 - MultiLater architecture

Empty proyect that follows the MultiLayer standard

## Folders
- controller
  - Handles HTTP requests and delegates processing to the service layer.
- service
  - Contains the business logic and coordinates application operations.
- repository
  - Manages database access and data persistence.
- model
  - Represents the application's domain entities.
- dto
  - Transfers data between layers without exposing domain models.
## Stack
- Java 26
- Spring Boot 4.x
- Maven

## Testing
- Postman

# 014-JPA_Relations
This project demonstrates how to manage database relationships using JPA and Hibernate in Spring Boot.
## Annotations
- OneToOne
- OneToMany
- ManyToOne
- ManyToMany
## Stack
- Java 25
- Spring Boot 4.x
- Maven
- MySQL 8.x
- JPA + Hibernate
- PostMan

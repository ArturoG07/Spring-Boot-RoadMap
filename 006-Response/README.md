# 006 - Response

Spring Boot application with a REST Controller using `@GetMapping` returning `@ResponseBody` and `ResponseEntity` responses.

Tested with Postman.

## Endpoints
- `GET /clients` — ResponseBody with a JSON list of clients
- `GET /responseentity` — ResponseEntity with a message and a 200 Http code
- `GET /notfoundresponse` — ResponseEntity with a message and a 404 Http code 

## Stack
- Java 26
- Spring Boot 4.x
- Maven

## Testing
- Postman
